# Dynamic Island for Windows

Плавающий чёрный «остров» в стиле iPhone Dynamic Island для Windows 10/11.
Приложение написано на Python + PySide6 (Qt WebEngine): интерфейс острова
рисуется HTML/CSS/JS, а системная часть — музыка, уведомления, микрофон и
камера — работает нативно через Windows Runtime и реестр.

## Скачать

Готовая версия для Windows 10/11 x64:

**[DynamicIsland.exe — Release v2.0.0](https://github.com/faze4ik/Dynamic-island---Windows/releases/download/v2.0.0/DynamicIsland.exe)**

Это один standalone EXE. Python и дополнительные файлы рядом не нужны.
При первом запуске он распаковывает Qt WebEngine во временную папку Windows,
поэтому первый старт может быть немного дольше обычного.

## Что умеет

- **Всегда чёрный остров.** Даже светлые темы меняют только акценты, стекло и
  иконки; сам остров остаётся чёрным. На чёрном фоне добавляется тонкая
  контрастная обводка.
- **Две формы.** Классический Dynamic Island и широкая чёлка iPhone XR. Чёлка
  прилегает к верхнему или нижнему краю выбранного экрана.
- **Шесть положений.** Сверху/снизу, слева/по центру/справа. Можно выбрать
  монитор и настроить отступы от краёв экрана.
- **10 тем.** iPhone Liquid Glass, Standard, Google Material, Midnight, Ocean,
  Sunset, Aurora, Cyberpunk, Graphite, Candy и любой свой акцентный цвет.
- **Музыка.** Компактный остров показывает текущий трек с эквалайзером. В
  раскрытом виде доступны название, исполнитель, прогресс, пауза/плей и
  переключение треков через системный медиаплеер Windows.
- **Звоночек уведомлений.** При новом уведомлении Windows появляется колокольчик
  с индикатором. Через заданное время (по умолчанию 60 секунд) он исчезает.
  Нажатие открывает центр уведомлений Windows.
- **Микрофон и камера.** Пока приложение использует микрофон или камеру, в
  острове появляются соответствующие значки. В раскрытом виде видно, какое
  приложение использует устройство. Нажатие открывает параметры
  конфиденциальности Windows.
- **Нагрузка ПК внутри острова.** В раскрытом острове рядом с часами и музыкой
  всегда видны живые индикаторы CPU и RAM с процентами и аккуратными полосами.
  Во вкладке «Система» остались только быстрые переходы в параметры Windows,
  диспетчер задач, центр уведомлений и папку настроек.
- **Без стартовых уведомлений.** При запуске приложение не показывает
  всплывающих сообщений и не открывает окна без запроса.
- **Автозапуск и сохранение.** Всё хранится в
  `%APPDATA%\DynamicIslandWindows\config.json`, там же лежит `app.log`.
  Изменения в настройках применяются сразу, а закрытие окна настроек крестиком
  сохраняет их. Отменяет изменения только явная кнопка «Отмена».
- **Правый клик.** Нативное контекстное меню: настройки, положение, форма,
  тема, автозапуск, центр уведомлений, конфиденциальность и выход.

## Запуск из исходников

```bat
run.bat
```

или:

```bat
.venv\Scripts\python.exe main.py
```

Если виртуального окружения ещё нет:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустить сразу с открытыми настройками:

```bat
.venv\Scripts\python.exe main.py --settings
```

## Управление

| Действие | Результат |
| --- | --- |
| Навести курсор | Раскрыть остров (если включено) |
| Клик по компактной пилюле | Раскрыть / свернуть |
| Правый клик по острову | Контекстное меню |
| Клик по колокольчику | Открыть центр уведомлений Windows |
| Клик по значкам микрофона/камеры | Открыть параметры конфиденциальности |
| Двойной клик по иконке в трее | Показать остров |
| Правый клик по иконке в трее | Меню трея |
| Кнопка «Скрыть» в раскрытом острове | Скрыть остров; вернуть через трей |

## Музыка, уведомления и приватность

- Музыка определяется через Windows Global System Media Transport Controls.
  Поддерживаются приложения, которые показывают трек в системном медиаплеере
  (Spotify, браузеры, Riff и другие).
- Для уведомлений приложение использует Windows `UserNotificationListener`.
  При первом запуске Windows может запросить разрешение. Если доступ запрещён,
  звоночек просто не появляется; музыка и индикаторы приватности продолжают
  работать.
- Микрофон и камера определяются по журналу доступа Windows
  `CapabilityAccessManager`. Показывается понятное имя приложения. Это
  индикатор, а не блокировка устройств.
- Скрыть звоночек можно в настройках → «Уведомления», там же меняется время
  автоматического скрытия.

## Сборка EXE

```bat
build.bat
```

Скрипт создаст `.venv`, установит зависимости, сгенерирует иконку и соберёт
один-единственный файл через PyInstaller:

```
dist\
  DynamicIsland.exe
```

Это полностью автономная сборка: рядом не нужны `_internal`, ZIP, README или
какие-либо другие файлы. `DynamicIsland.exe` можно скопировать на другой
компьютер с Windows 10/11 x64 и запускать как есть.

> При первом запуске однофайловая сборка распаковывает Qt WebEngine во временную
> папку Windows, поэтому старт может занять на несколько секунд больше. Это
> нормально; после закрытия временные файлы удаляются автоматически.

## Структура проекта

```
dynamic-island-windows/
  app/
    main.py        — запуск приложения, трей, единственный экземпляр
    window.py      — окно острова, маска, позиционирование, мост JS
    settings.py    — вкладки настроек: общие, оформление, уведомления, система
    config.py      — конфиг, 10 тем, положения, формы, пути
    native.py      — музыка, уведомления, микрофон/камера, системные ссылки
    autostart.py   — автозапуск через реестр Windows
    style.py       — оформление диалогов и меню
  assets/
    island.html    — встроенный интерфейс острова
    icon.ico/png   — иконка
    version_info.txt
  tools/make_icon.py
  main.py          — точка входа
  build.ps1        — сборка PyInstaller
  dynamic_island.spec
```
